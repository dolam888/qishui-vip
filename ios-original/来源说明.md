## 为什么放在这里

本仓库的安卓版（上一级目录的 `__init__.py`）是从这份 iOS 代码改写而来，保留原版便于对照：哪一段业务逻辑是继承的、哪一段是为安卓适配重写的，可以直接 diff 出来。

## 这份原版能不能直接跑

**不能。** 它只写了 `ascript.ios.*` 接口，依赖 iPhone 上的 WebDriverAgent 驱动，Windows / 安卓都跑不起来。想在安卓上跑请用上一级的安卓版。

## 相对原仓库的改动

只有两点，其余文件原样保留：

- 原 `README.md` 重命名为 `README-原版.md`，避免与本仓库主 README 冲突
- 删除了 macOS 的 `.DS_Store` 和 `.git/` 目录（克隆残留，不属于源码）
